El problema
El dinero se escapa sin que lo notes.

Gastos hormiga, recibos perdidos, presupuestos olvidados y cero visibilidad real. ControlCash nace para resolver estos problemas con tecnologia real: IA, OCR y automatizacion.

💰

Gastos invisibles

Sin un sistema de registro, las suscripciones olvidadas y cargos recurrentes se acumulan. ControlCash registra cada movimiento con categorias personalizables y alertas de presupuesto al 80% y 100%.

📄

Recibos perdidos

El OCR con NVIDIA Nemotron Parse extrae total, fecha, comercio e items de cualquier foto de recibo. Pipeline multi-ronda con tool calls internos para maximizar precision.

📈

Cero visibilidad

Reportes con Chart.js: donut por categoria, tendencia diaria 30 dias, comparativo de periodos. Exporta a PDF (jsPDF), Excel (SheetJS) o CSV (Flask).

🔒

Seguridad insuficiente

JWT con access token (15 min) + refresh token (7 dias, hash SHA-256 en DB). Cifrado AES-256-GCM con PBKDF2. Rate limiting con Flask-Limiter. Headers CSP, X-Frame-Options.

🕐

Registro manual tedioso

Recurrencias automaticas: configura gastos recurrentes (diario, semanal, quincenal, mensual, anual) y el sistema los ejecuta automaticamente con un job diario en background.

🎯

Metas sin seguimiento

Presupuestos por categoria con barras de progreso, alertas visuales y comparativo mes a mes. La IA genera un perfil financiero con score 0-100 y habitos detectados.

La solucion
129 features reales implementadas.

Arquitectura
3 capas bien separadas.

Separacion de responsabilidades: datos, negocio y presentacion. Cada capa es independiente y testeable por separado.

Capa de datos

db/

PostgreSQL + MySQL/MariaDB con auto-seleccion. 10 tablas, repositories pattern, cifrado AES-256-GCM. Schema DBML.

pg_repository.py mysql_repository.py crypto.py (400 LOC) schema.dbml
Capa de negocio

api/

Flask REST API con 48 endpoints. JWT auth, rate limiting, CORS, headers de seguridad. Modulos OCR (NVIDIA NIM), LLM (chat + perfil), push notifications.

app.py (2,347 LOC) ocr.py (1,359 LOC) llm.py (1,224 LOC) jwt_auth.py (284 LOC) push.py (202 LOC)
Capa de presentacion

app/

HTML/CSS/JS vanilla + Chart.js + jsPDF + SheetJS. Glassmorphism UI, PWA con service worker, Capacitor para mobile (Android/iOS).

index.html (2,368 LOC) styles.css js/auth.js, movimientos.js js/charts.js, presupuestos.js js/ia.js, gemini_live.js
